## Befund

QA-Aufnahme vom 2026-11-10 (iOS 1.0.8, Build 60), `backgroundLayDiagnostics.timeline`
(nur Ereignisnamen/Zeiten, keine Standortdaten):

| Zeit | Ereignis |
|---|---|
| 58 ms | `backgroundPermission undetermined` |
| 91 ms | `backgroundPermission denied` (Antwort auf `requestBackgroundPermissionsAsync`) |
| 5,5 s | `inactive` / `resume` (Systemdialog) |
| danach | `backgroundPermission granted`, aber `taskStartAttempt: 0`, `taskRegistered: false` |

Ursache: `useTrackRecorder.beginRecording` fragte die Freigabe einmal direkt nach
Aufnahmestart ab. iOS antwortet bei `undetermined` sofort mit `denied` und zeigt den
Dialog erst später. Der AppState-Listener protokollierte die spätere Freigabe nur
(«Observation only»), `startBackgroundUpdates` wurde nie mehr aufgerufen. Die Aufnahme
lief ausschliesslich über den Vordergrund-Strom und kann bei gesperrtem Display abbrechen.
In der folgenden Aufnahme (Freigabe bereits erteilt) startete der Task normal.

## Bekannte Risiken / offene Punkte

- **Geräteprüfung steht aus** (nicht ausgeführt): frische Installation von Build 60 mit dieser
  Änderung, Aufnahme starten, «Immer» erst im Systemdialog erteilen, Display sperren, Aufnahme
  läuft weiter; im QA-Export danach `taskStartAttempt ≥ 1` und `taskRegistered true` in derselben
  Aufnahme. Die Annahme, dass iOS nach dem Dialog AppState `active` meldet und die Freigabe dann
  bereits `granted` liest, stützt sich auf die eine QA-Timeline oben, nicht auf einen Gerätetest
  dieser Änderung.
- Erteilt die Nutzerin die Freigabe, ohne dass die App den Vordergrund verlässt und wieder betritt
  (kein AppState-Wechsel), gibt es keinen Nachstart-Auslöser. Beim iOS-Systemdialog und beim Umweg
  über die Einstellungen entsteht der Wechsel.
- Schlägt der späte native Start fehl, bleibt der Vordergrund-Strom aktiv; es gibt bewusst keinen
  automatischen Wiederholungsversuch (wie beim bisherigen direkten Start).
- Android nutzt denselben Pfad (Rückkehr aus den Einstellungen); dort nicht separat geprüft.
- Kein unabhängiges Code-Review ausgeführt.
