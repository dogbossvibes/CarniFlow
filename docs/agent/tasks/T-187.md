## Ergebnisse
Fachliche Hinweise der DB-Suite für T-184 (Entscheidung beim T-184-Owner):
1. Ältere App (Build 57) kann eine Lernstufen-Übung nicht mit 3 Sternen speichern – ganzer Save scheitert mit SQLSTATE 23514 (kein Datenverlust, aber Speicherfehler).
2. Ältere App speichert 1/2/4/5 Sterne auf Lernstufen-Übungen → Wert bleibt als Lernstufe markiert (Bedeutung verschiebt sich).
3. Constraint erlaubt `rating_scale='lernstufe'` mit `rating` NULL.
4. Explizites `rating_scale: null` entfernt die Markierung.
